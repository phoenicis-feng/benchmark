8. 孤立道路网络无法借用另一网络的水电。

12. 公共服务预算与距离污染。
13. 水电不足限制岗位，扩容恢复。
14. 收入、支出与资金月结守恒。
15. 贷款额度、固定还款与 36 个月到期。
16. 受损建筑停用与 3 个月自动修复。
17. 住宅在教育、需求、入住率与幸福度达标时升级。
18. 里程碑奖励一次性发放、完成后继续模拟。
19. 存档恢复后保持相同模拟和随机事件序列。
20. 拒绝损坏、非法和越界存档。
21. 财政透支导致迁出，贷款后可恢复经营。
22. 600 个月运行中的每月不变量。
23. 拒绝继承属性作为建筑或预算键。
24. 贷款后旧建造不可撤销，避免覆盖现金交易。

## 14 项浏览器验收范围

离线启动与引导；实际地块点击、资金扣除和撤销；拖动铺路；逐月推进与暂停；税率、道路预算和贷款；保存、读取与重载；三张趋势图和七种地图图层；缩放、检查与快捷键；导出和重新导入；空白新城与指南；4 倍速持续运行；小屏无溢出、居中与拖动；大城市导入和连续模拟；非法导入报错且不改变当前城市。

浏览器测试从页面按钮、滑块和 Canvas 指针事件完成主要交互。大城市持续运行使用与页面同一月结入口推进，没有修改城市指标。

## 经营路径实测

自动经营脚本从默认起步小镇出发，只通过正式建造接口支付费用；没有注入资金、居民或岗位。先发展盈利社区，再建设干路和公共服务，并随人口增加扩充水电。该项关闭可在游戏中关闭的随机火灾，以验证发展路径；另有开启火灾的 600 个月测试和确定性存档恢复测试。

第 408 个月状态：

| 指标 | 实测值 |
| --- | --- |
| 人口 / 住房 | **12,230 / 12,270** |
| 在岗人数 / 有效岗位 | **6,686 / 9,085** |

高拥堵仍然降低收入和幸福度，表明完成目标后依然存在经营压力。目标按历史达成条件记录，不会因为后续拥堵上升而撤销。少数无道路邻接的地块仍停供，整体建筑水电覆盖约 98.6%；全城容量充足不能替代正确的地块连接。

## 已发现并修复的问题

- 透支期间仍允许迁入：改为停止迁入并额外迁出。
- 火灾停用住宅保留住户：改为居民撤离，修复后重新发展。
- 贷款到期后面板仍计下月还款：在月结后刷新预测预算。
- 撤销旧建造覆盖新到账贷款：贷款交易使旧撤销失效。
- 远端独立网络岗位错误吸引迁入：按住宅所属道路网络计算岗位空余。
- 大城市反复对每个岗位单独寻路：每个住宅道路端点只生成一次最短路径树，公共服务与污染源分组索引。
- 滑块拖动因面板重建中断：输入时更新数值，完成调整时重算面板。
- 工具按钮聚焦时字母快捷键不工作：修正快捷键焦点规则。
- 手机切换视口后地图偏到屏幕外：大幅改变视口时重新居中并允许全图缩放。
- 快速拖动铺路遗漏中间格：插值补齐连续地块。
- 水电图层对道路显示错误停供：按所属网络的实际供需渲染道路。

- `tests/engine-results.txt`：逻辑测试原始输出。

```sh
npm test
npm run build
node tests/progression.cjs
node tests/performance.cjs
node tests/browser.cjs  # 需要已安装 Playwright / Chromium
```

浏览器实测覆盖 Chromium；Safari 和 Firefox 未实测。游戏没有在线多人或后台服务器，所有模拟和存档都在浏览器本地进行。
